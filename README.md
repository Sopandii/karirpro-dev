# KarirPro Development Repo

Repo pusat semua kerjaan KarirPro: theme, SEO, konten, n8n, dan dokumentasi.

## Struktur
```
theme/karirpro-theme/     → Theme WP (from Docker container)
seo/                      → SEO checklist, sitemap, meta fixes
content/                  → Draft artikel / konten
scripts/                  → Automation scripts (cron, deploy)
plans/                    → Perencanaan & roadmap
references/               → Referensi eksternal / catatan
```

## Quick Commands

```bash
git add .
git commit -m "update: ..."
```
